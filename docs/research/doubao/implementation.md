## 聊天记录消失修复（2026-10-31）

复现并修复三个问题：多个页面各持旧快照，整份写入 localStorage 会覆盖其他页面新增的会话；重新生成先移除旧回答，失败后无法回看；旧记录中一条异常数据会导致整份历史加载失败。

改为逐会话浏览器缓存、按消息 ID 和版本合并、多页面同步，并在本机服务 `.data/conversations/` 下原子写入备份。旧格式逐条迁移，异常记录不影响正常记录，也不覆盖旧缓存。删除使用墓碑标记，避免旧页面复活已删除会话。重新生成保留原回答，后续请求仅使用最新成功版本。页面显示保存状态；浏览器存储不足时可从本机服务恢复。

验证：

- 三个对应的 React 页面回归测试先复现失败，修复后通过。
- `npm run build` 通过；`npm test` 共 32 项通过，覆盖大记录、存储额度不足、并发快照、删除、服务重启、异常记录和中断后的部分文本保留。
- 实际浏览器从不同页面迁移合并 7 个既有会话、34 条消息；随后新增验证会话，真实模型返回“保存成功”，刷新后正文仍在。
- 另一已打开页面自动收到新增会话，当前正在查看的历史正文保持原样。

保存的是已收到的文本；刷新页面仍会中止当前上游生成，本次未接入服务端后台生成或流式断点续跑。

## 长回复卡顿与中断恢复（2026-10-31）

用户进一步确认：生成长回答时卡住，刷新后仍显示 network error。检查时 `/chat` HTTP 响应约 2ms，实际长会话刷新约 0.4 秒；错误已经保存在上一条未完成回答中，并非刷新请求再次报错。网关偶发断流未稳定复现，未据此声称已修复上游网络。

确定复现的性能问题是每个流式片段都触发整个页面及历史 Markdown 重新解析。测试中 300 个片段触发 2434 次 Markdown 渲染，耗时约 5.1 秒；输入几次文字也会触发 24 次解析。现改为约 80ms 批量更新、生成期间轻量文本显示、完成后 Markdown 排版，以及缓存已完成回答。相同片段测试约 0.14 秒通过，正文无损；历史同步状态不变时也不再重新渲染。

对网络错误统一显示保留内容与恢复指引；最后一条有正文的中断回答支持「继续生成」，将原正文送入上下文并追加续写。成功后可清除旧错误/停止标记，刷新仍保留。续写是新的模型请求，不是原 SSE 连接的精确断点续传。

`npm run build` 通过，`npm test` 共 36 项通过；新增回归覆盖长回答输入、流式批量渲染、网络中断后刷新续写及服务重启/旧快照下清除完成标记。实际浏览器已验证长回答完成、生成期间输入、主动停止保留正文，以及刷新后继续生成至 10251 字符并再次刷新恢复。服务已重新启动加载共享合并逻辑。

## 生成中刷新自动恢复（2026-10-31）

原 CLI 的 `src/cli/transports/SSETransport.ts` 有序号、Last-Event-ID、心跳和退避重连；该协议依赖原会话服务，独立网页没有接入。网页原 `/api/chat` 将上游请求绑定浏览器连接，`res.close` 会取消模型请求，之前的「继续生成」是新的续写请求，无法解决刷新本身导致的断流。

现将模型与技能调用提取到 `server/completion.mjs` 共用，通过 `server/runs.mjs` 创建服务端后台任务：

- `POST /api/runs` 使用固定 ID 和请求指纹，重复提交不再调用模型；同一对话并发生成被拒绝。
- `GET /api/runs/:id/events` 仅订阅进度。断开不取消生成，按序号恢复最新完整快照，避免重复追加；15 秒心跳，前端 45 秒无字节重新订阅并退避重试。
- 正文、推理、工具参考和用量通过任务快照保存到 `.data/runs/`，同时投影到原会话存储；任务终态保存后才向订阅者确认。
- 前端根据持久化 runId/runStatus 自动跟踪任务；只有显式 `POST /api/runs/:id/cancel` 才执行用户停止。订阅者抛错不会影响后台生成。
- 服务进程重启会明确标记旧任务中断并保存正文，不自动重发模型请求；已完成任务可直接从磁盘恢复。损坏任务文件保留，不阻断其余服务。
- 浏览器缓存丢失或存储额度不足时，恢复对话并自动选择其正文，避免被初始化空对话遮住。

验证：生产构建及 42 项自动测试通过。新增实际组件卸载/重挂载、HTTP 断订阅/重订阅、同 ID 幂等、显式取消、服务硬重启、订阅异常和坏文件隔离回归。真实 DeepSeek 长回答生成时连续刷新两次，同一任务从序号 428 持续至 5643，最终保存 7660 个 Markdown 字符，页面无中断错误。升级前已经终止的旧回答仍需点一次「继续生成」来创建新任务。
